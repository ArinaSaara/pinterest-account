Privacy Policy

App: pinterest-account (personal content automation tool)
Last updated: 18 October 2026

What this app does

This is a personal, single-user tool. It generates pin images from templates and publishes them to boards on the owner's own Pinterest account using the Pinterest API v5. It requests only the scopes needed for that: boards:read, pins:read and pins:write.

Data we collect

The app does not collect, store or process any personal data of other Pinterest users. The only data it handles is the owner's own Pinterest access token, board list and the pins it creates.

Where data is stored

The access token is stored locally on the owner's computer in a configuration file that is never committed to version control or sent anywhere except to the Pinterest API.

Third parties

No data is sold, shared or transferred to third parties. The app communicates only with the official Pinterest API endpoints.

Data deletion

Access can be revoked at any time by removing the app in Pinterest account settings or by deleting the local token file. No copies of data are kept elsewhere.

Contact

Questions about this policy can be sent through the repository's GitHub issues page.
